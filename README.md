# Motion Blur

Motion blur for elements that move on the web. Read how it works, with live examples, in [the write-up](https://www.raphaelsalaja.com/work/motion-blur).

```sh
npm install @web-kits/motion-blur
```

The API and options are in the [package README](./packages/motion-blur/README.md).

## Development

The library is in `packages/motion-blur`:

```sh
pnpm install
pnpm build
pnpm typecheck
```
